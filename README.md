# ぴったり10をつくろう！ — 試作版

「すくすく」向けの四則演算ゲームサイトです。

## 現在できること

- 生徒コードでログイン（体験用: `SUKU01`）
- 今日の1問、簡単、普通、チャレンジ
- 式をサイト側で判定し、正解時にポイントとコインを付与
- 50コインで、かぶりなしガチャ
- ポイントによるキャラクター成長、アイテム着せ替え
- 授業コードによる出席ボーナスと参加スタンプ
- 管理画面で授業コード発行、生徒コード作成・停止、数値調整、CSV保存

管理画面は `/admin` です。現在は端末内だけで動く確認用画面で、管理者認証はまだありません。

## 現段階の注意

この試作版はブラウザ内保存です。同じブラウザでは生徒画面と管理画面が連動しますが、端末をまたぐ同期はまだ行いません。本番運用前にデータベース保存と安全な管理者認証へ切り替えます。

問題は動作確認用の最小構成です。正式な問題バンクと出題条件は、画面・運用の確認後に最後の工程で設定します。

## 開発

```bash
pnpm install
pnpm dev
```

品質確認:

```bash
pnpm lint
pnpm build
```
